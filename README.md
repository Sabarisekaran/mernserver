# MERN Server – Full Stack Project Setup & Deployment

A complete MERN stack project structure built using **React.js**, **Node.js**, **Express.js**, **MongoDB**, and **Tailwind CSS**.  
This project demonstrates the complete workflow from local development to deployment using **Vercel** and **Render**.

---

## 🚀 Tech Stack

### Frontend
- React.js
- Tailwind CSS
- Axios
- React Router

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- dotenv

### Deployment
- Vercel (Frontend)
- Render (Backend)

---

## 📂 Project Structure

```bash
mernserver/
│
├── client/          # React Frontend
├── server/          # Node.js Backend
├── .env.example
├── .gitignore
└── DEPLOYMENT_GUIDE.md
```

# ⚙️ Workflow of the Project

## 1️⃣ Frontend Setup
- Created React application
- Installed Tailwind CSS
- Designed responsive UI components
- Connected API using Axios
- Managed routing and page structure

---

## 2️⃣ Backend Setup
- Created Express server
- Configured REST APIs
- Connected MongoDB database
- Added environment variables using dotenv
- Tested APIs locally

---

## 3️⃣ Full Stack Integration
- Connected frontend with backend APIs
- Managed request & response flow
- Handled CRUD operations
- Tested complete application flow

---

## 4️⃣ Deployment Process

### Frontend Deployment
- Uploaded frontend to GitHub
- Connected repository with Vercel
- Configured build settings
- Deployed React application

### Backend Deployment
- Uploaded backend to GitHub
- Connected server with Render
- Added environment variables
- Deployed Node.js backend APIs

---

# 🔄 Application Flow

```text
User Interface (React + Tailwind)
            ↓
API Requests (Axios)
            ↓
Node.js + Express Server
            ↓
MongoDB Database
            ↓
Response Sent Back to Frontend
```

# 🛠️ Installation

## Clone Repository

```bash
git clone <repository-link>
```

## Frontend Setup

```bash
cd client
npm install
npm run dev
```

## Backend Setup

```bash
cd server
npm install
npm start
```
